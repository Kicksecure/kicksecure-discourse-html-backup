arraybolt3 September 27, 2026, 8:36pm 4

Brave Browser is based on Chromium, and the bug was introduced in Chromium, so yes, it is very likely the issue.

Keep in mind that every time you open Brave, it will (likely) re-create the bad fontconfig cache, and you’ll need to remove it again. If you find this too annoying, you can create empty /home/user/.cache/fontconfig and /home/user/.fontconfig directories, then use sudo chattr +i on both of them to prevent Brave (or anything else) from writing to them. (You’ll have to do this from sysmaint mode unless you removed user-sysmaint-split.) This will break the fontconfig cache, but in my experience this doesn’t result in any real issues. There might be a loss in performance when starting apps, but if there is, I haven’t noticed it.
