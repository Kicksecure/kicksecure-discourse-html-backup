arraybolt3 October 14, 2026, 11:24pm 2

The only thing in Kicksecure that I can immediately think of that could cause this is a hardening setting change, but there haven’t been any notable hardening setting changes recently.

It isn’t guaranteed that this is a Kicksecure bug, as it is theoretically possible that the hardware is failing. Some debugging steps to take are:

  • Download the Kicksecure ISO and boot from it. See if the system is usable in ISO live mode.
  • If the system is functional that way, install Kicksecure on a second drive and fully update it. See if the system is usable (perhaps you changed a configuration setting that broke something).
  • If the system is not functional after that, download and install a Debian live ISO, and install it to a second drive, enabling disk encryption in the process. Then fully update it. See if the system is usable. This will tell us if the issue is somehow specific to Kicksecure or not.

Reporting Guidelines - Bug Reports, Software Development, and Feature Requests
