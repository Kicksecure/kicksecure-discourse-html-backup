arraybolt3 August 6, 2026, 12:30am 2

We had derivative-maker in three spots:

  • “Kicksecure-specific”, still very much alive and active: GitHub - Kicksecure/derivative-maker: Build tool for Kicksecure and Whonix derivative images · GitHub
  • “Whonix-specific”, really just a mirror of the above: GitHub - Whonix/derivative-maker: Build tool for Kicksecure and Whonix derivative images · GitHub
  • “Distro-agnostic”, this one ended up being useless, it previously was just another mirror of the above two, it’s the only one that’s archived: GitHub - derivative-maker/derivative-maker: https://www.kicksecure.com/wiki/Imprint · GitHub

So don’t worry, the project is still very alive. The archival in one spot is just an artifact of us cleaning up unused cruft.

phil-gg:

Your derivative-maker tool is particularly of interest to me, as a way to move large chunks of config out of my post install dotfile scripts into the build installation image step instead.

You may want to be careful here; derivative-maker is the build system for Kicksecure and Whonix, and as such it regularly undergoes invasive changes as we continue to develop the OS. You may have to update your soft-fork of the repo regularly as it updates.
