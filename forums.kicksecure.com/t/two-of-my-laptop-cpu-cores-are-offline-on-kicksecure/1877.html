You’re most likely running into a consequence of hyperthreading being disabled in Kicksecure. Hyperthreading allows a single CPU core to “pretend” to be multiple cores; this provides greater performance in some situations, but also opens the door for entire families of CPU vulnerabilities like L1TF/Foreshadow. It is therefore recommended that you leave hyperthreading disabled and ignore the offline CPU “cores”.

If you want to enable hyperthreading anyway, you may be able to use the instructions here to add the smt=-1 parameter to your kernel command line:
