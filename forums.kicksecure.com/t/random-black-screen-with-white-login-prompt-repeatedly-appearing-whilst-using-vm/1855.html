Did you set up the VM according to the instructions at:

Kicksecure – 24 Sep 26

Kicksecure for KVM

Kicksecure for KVM

If not, you may want to recreate the VM following those instructions.

Did you make any other customizations to the VM’s graphics configuration, like changing to an emulated graphics card other than “virtio”? If so, undo those changes and see if that makes things better.

It’s theoretically possible SimpleX could be the culprit. What you might try is: clone the VM, uninstall SimpleX from the clone, then use the clone for everything but SimpleX, and use the original only for SimpleX. if the VM with SimpleX running crashes, and the one without SimpleX doesn’t crash, then you know that SimpleX is almost certainly at fault.
